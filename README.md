# SQL Employee Management System

## Project Overview
This project focuses on designing and managing an Employee Management Database using MySQL.

It demonstrates practical SQL skills through employee records, department management, data retrieval, filtering, joins, aggregate functions and subqueries.

## Objectives
- Create and manage employee databases.
- Store employee and department information.
- Retrieve and analyse employee records.
- Perform salary-related analysis.
- Practise SQL queries using real-world business scenarios.

## Technologies Used
- MySQL
- SQL
- DBeaver Community
- GitHub

## Database Structure

### Employees Table
- Employee ID
- Employee Name
- Age
- Salary
- Department ID
- Hire Date

### Departments Table
- Department ID
- Department Name

## SQL Concepts Covered
1. CREATE and INSERT
2. SELECT and WHERE
3. ORDER BY and DISTINCT
4. GROUP BY and HAVING
5. Aggregate Functions
6. INNER JOIN and LEFT JOIN
7. Subqueries
8. Views
